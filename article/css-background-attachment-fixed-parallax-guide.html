CSS Background-Attachment Fixed Parallax Guide

The CSS background-attachment: fixed parallax technique creates an illusion of depth on web pages by locking a background image to the viewport while foreground content scrolls normally. This article explains the functional purpose of this pure CSS effect, how it creates a parallax illusion without complex code, its primary benefits, and practical considerations for modern web development.

How the Technique Works

By default, an element's background image scrolls along with the rest of the page because background-attachment defaults to scroll. When set to fixed, the background image is positioned relative to the browser’s viewport rather than its containing element.

As the user scrolls down, the element itself moves up the screen, acting like a moving window or "cutout." The image behind it remains locked in place relative to the screen, revealing different portions of the static graphic through the moving container.

.parallax-section {
  background-image: url('hero-image.jpg');
  background-attachment: fixed;
  background-position: center;
  background-repeat: no-repeat;
  background-size: cover;
  min-height: 400px;
}

The Purpose in Web Design

The primary goal of the background-attachment: fixed technique is to enhance user engagement and visual storytelling through layered depth.

  • Simulating Depth (Parallax): Parallax scrolling relies on the human visual perception that objects farther away move slower than objects close by. Keeping the background static while foreground text moves simulates infinite distance.
  • Creating Visual Breaks: Web designers use fixed background sections between content blocks to create natural resting points for the reader's eyes in long-form landing pages.
  • Highlighting Imagery: It presents full-bleed photography or branding graphics prominently without taking up permanent screen space.

Advantages Over JavaScript Solutions

Traditional parallax effects often rely on JavaScript scroll event listeners to calculate and update CSS transform properties in real time. The background-attachment: fixed approach offers distinct advantages:

  • Zero Script Overhead: It requires no external libraries or custom JavaScript code, keeping page payloads small.
  • Simple Implementation: Adding a single CSS rule to an existing class achieves the effect instantly.
  • Main-Thread Efficiency: Because it avoids JavaScript scroll listeners, it eliminates common scroll-lag (jank) caused by blocking the browser's main execution thread.

Caveats and Mobile Considerations

While convenient, the technique has limitations developers must account for:

  • Mobile Browser Performance: Many mobile browsers, including iOS Safari, disable or poorly support background-attachment: fixed due to the high battery and GPU cost of repainting large fixed backgrounds on mobile hardware. Media queries are often necessary to fall back to background-attachment: scroll on small screens.
  • Accessibility: Rapidly moving foreground elements over static backgrounds can trigger vestibular disorders or motion sickness. Developers should use the @media (prefers-reduced-motion) query to provide a static, non-scrolling background alternative for users who have requested reduced motion in their system settings.
